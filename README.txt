たぬっき v0.3 試作品

このフォルダは、ブラウザで動くPWAアプリのソース一式です。
index.html を開くと基本画面を確認できます。ただしファイルプレビューではJavaScriptが動作しない場合があります。

本格的に動作させるには、フォルダをHTTPS対応の静的サイトホスティング（GitHub Pages、Netlify等）に配置してください。
HTTPSで一度開くと、Service Workerが対応環境で必要なファイルをキャッシュし、以後オフライン起動できます。
iPhoneではSafariの共有メニューから「ホーム画面に追加」でアプリのように起動できます。

注意：家族共有、アカウント、端末間同期、閉じている間のプッシュ通知は未実装です。
リマインダーは試験機能で、アプリが開いている間のみチェックします。
記録データはブラウザのlocalStorageに保存されます。ブラウザデータを消すと消失する可能性があるので、設定からJSONバックアップしてください。
医療情報を含む体調記録の取り扱いには注意してください。公開用のセキュリティ設計は未完成です。
